# RLI — Conceitos e Redes das Leis de Inovação

Pacote de publicação no Streamlit Community Cloud.

## Publicação

1. Crie um repositório no GitHub e envie todo o conteúdo desta pasta, mantendo a estrutura.
2. Acesse https://share.streamlit.io e selecione **Create app**.
3. Escolha o repositório e a branch utilizada.
4. Informe `app.py` como arquivo principal.
5. Defina o endereço desejado e clique em **Deploy**.

O `app.py` funciona somente como camada de apresentação no Streamlit. Os dados,
as nuvens e as redes são produzidos pelo pipeline `build_site.R`, preservado em
`site/build_site.R` para reprodutibilidade.
